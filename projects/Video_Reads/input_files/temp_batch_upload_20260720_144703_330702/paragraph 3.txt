With that answered, the script moves into installing dependencies. Watch the terminal here — you'll see it pulling in git, Python 3, and a handful of system libraries Mal trail needs to build and run. One dependency is worth calling out specifically: pcapy-ng. Mal trail depends on a packet capture library called pcapy, but the original pcapy package is deprecated and causes real problems on modern Python 3 environments. pcapy-ng is a maintained fork that's a drop-in replacement, and it's what the script installs instead. If you ever see a Mal trail install fail at the packet capture step outside of this script, this mismatch is almost always why.
