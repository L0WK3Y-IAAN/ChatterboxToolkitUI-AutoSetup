Run an nslookup against morphed.ru from the sensor host, then switch over to the server's dashboard. If the event shows up there, you've confirmed the full path: the sensor on one machine captured the traffic, matched it against its threat feeds, and successfully reported it over the network to a server running somewhere else entirely. The sensor column in the event table is worth watching here too — it identifies which sensor a given detection came from, which becomes essential once you're running more than one.
