Before jumping into the install, a quick word on environment. This demo runs on a fresh Ubuntu Server 24.04 instance, with the sensor and server on one host — the simplest setup, and the one most people start with. How you provision that box is up to you: a VMware Workstation VM, VirtualBox, a cloud VPS, or bare metal all work the same way from here on out. If you want a reference spec for a lab environment, two vCPUs and two gigabytes of RAM is plenty.
