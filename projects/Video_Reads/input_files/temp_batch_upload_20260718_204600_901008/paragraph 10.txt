Once installation is done, the script detects the machine's IP address so it can tell you exactly where the dashboard will be running, and then offers to start both the server and the sensor for you — each one launched inside its own tmux session, named maltrail-server and maltrail-sensor. Running them in tmux means they'll keep running even if the SSH connection drops, and you can reattach to either one any time to watch its live output.
