The script starts by checking whether Mal trail is already installed at /opt/maltrail. If server.py and sensor.py are already there, it skips the install entirely and jumps straight to a status check — is the server running, is the sensor running, in tmux sessions — then offers to start whichever one isn't. That fast path matters if you re-run the script on a box you've already set up; it won't reinstall or overwrite anything.
